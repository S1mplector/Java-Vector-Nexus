# What's New in JVN 0.7.0

JVN 0.7.0 introduces a custom **source-available attribution license**. Engine
source and utilities remain publicly available, and commercial games are
permitted under the license. This is not an OSI-approved open-source license.

- **Review and accept the terms:** Hub, Editor, Launcher, and game exports now
  require acceptance of the current license and terms. Receipts stay on your
  computer; nothing is automatically uploaded. Game players do not need to
  accept developer terms.
- **Required Settings credit:** exported games must visibly display
  **Made with [official JVN SVG logo] (engine version)** in Settings. The engine
  supplies Settings access and the credit; project options cannot hide them.
- **Final release checks:** packages are checked for the expected runtime jars,
  engine version, official logo, and license notices before release or publishing.

Game creators retain ownership of their independent content. Failure to comply
can remove distribution permission under the license; it does not automatically
transfer ownership of a game. Local receipt signatures check integrity, not
verified identity or trusted acceptance time.
