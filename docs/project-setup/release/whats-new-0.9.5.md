# JVN 0.9.5

- The tutorial title screen puts its four buttons in a horizontal row below the title. JVN also corrects the stock layout in older wizard-generated tutorial projects when they run on the updated engine.
- Ginger welcomes you when you start the tutorial and shows the script behind her greeting. The course adds live source examples for backgrounds, movement, choice routes, build checks, lighting, and rendering performance.
- Create a new Tutorial project or open the downloadable Tutorial project to get the revised lessons.
