# JVN 0.9.2

## Pip’s tutorial

In New Project, select **Tutorial Workspace with Pip** and click **Create Pip Tutorial**. Run the project and choose **Start tutorial**. Pip meets you at the topic menu for all 30 lessons.

The template choices are now radio buttons. The create button confirms when the course is selected. A Starter Story game points you to the correct template from its tutorial branch. Existing projects keep their own scripts and assets.

## Run and Build & Publish

Both workspaces now use the active Editor theme for their backgrounds, toolbar gradients, borders and selected controls. The dark theme uses the Editor’s graphite palette.
