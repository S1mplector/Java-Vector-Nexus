# JVN 0.9.4

## Visual layout editing

Layout Studio opens in **Design** with the JavaFX game renderer at the project’s resolution. Build menus with buttons, headings, text, and notes. Drag and resize items, set actions and styles, and preview dialogue, choices, narration, NVL, and bubbles. **Design** and **Source** share one document and undo history. [Layout Studio guide](../../scripting/ui/layout/tooling/layout-editor-tools.md)

## Script editing and documentation

VNS, JES, and property editors have clearer syntax highlighting and completion. The VNS minimap shows the whole script with a glass viewport and a dedicated diagnostic rail. The wiki highlights VNS, JES, layout properties, and common languages in fenced code blocks. [Editor guide](../../editor/core/editor.md)

## New games and the tutorial

Choose **Writing Project**, **Tutorial**, or **Blank Sandbox** in the redesigned New Project wizard. Tutorial includes 30 lessons with direct explanations and syntax-highlighted examples. [New Project wizard](../onboarding/new-project-wizard.md) · [Tutorial guide](../../guides/jvn-tutorial.md)

## Editor tools

Trashman has a redesigned heap monitor and cleanup controls. Editor menus and dialogs use new icons, and the source launcher pins the running editor’s dependencies so rebuilding a project can safely update Gradle’s output jars. [Editor tools](../../editor/sidebars/overview/sidebar-utilities.md)
