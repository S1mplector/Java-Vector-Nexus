## Build & Publish

Choose Portable ZIP, Desktop bundle or Native installer in the Package page. The Build window keeps the selected target and Ship action visible while you review checks, prepare a release profile or inspect artifacts. The Editor and standalone launcher open the same workspace in the active theme.

## Run and create a tutorial

**Run** opens **JVN Run Workspace** with Output and Render inspector. The fast launcher refreshes its classpath after a revision, version or workspace change. The packaged Editor includes the build services it needs to start from a clean installation.

Choose **Tutorial Workspace** in the New Project window to create Pip’s monochrome course. Start the tutorial to see its topic menu and pick any of the 30 lessons. The new project uses the guided course’s own scripts, characters and presentation.
