# JVN 0.9.3

In **New Project**, choose **Tutorial Workspace with Ginger**, create the project, press **Run**, and choose **Start tutorial**. Ginger guides all 30 lessons. Each lesson returns to its category and remembers completion. Choose a reply with the mouse or the arrow keys and Enter.

Pause, Settings, Save and Load use the tutorial’s illustrated paper layout. Settings show slider values and toggle states. Save slots show thumbnails when available. Existing workspaces retain their own scripts and menus.
